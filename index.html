Never lose your .env files again

envsync automatically syncs your environment configuration across every git worktree. One command. Zero config.

Install Now View on GitHub
$ curl -sSL https://raw.githubusercontent.com/DukeeTheProgrammer/envsync/main/install.sh | bash
The Problem

Git worktrees are great. Until they aren't.

Worktrees give you isolated code branches, but your .env files are gitignored. Every new worktree starts blind.

Without envsync
$ git worktree add ../feature-login -b login $ cd ../feature-login && npm run dev Error: DATABASE_URL is not defined Error: Missing PORT in environment Where is my .env? Gone. $ cp ../main/.env . # manual copy... every time $ cp ../main/.env.local . # forget this one? good luck
With envsync
$ git worktree add ../feature-login -b login $ cd ../feature-login && envsync sync copied .env copied .env.local Synced 2 file(s). $ npm run dev Server running on port 3000
How It Works

Three commands. That's it.

envsync detects your main worktree, finds all .env files, and keeps them in sync.

Check Status
$ envsync status envsync status ──────────────────────────────────────── Found 2 .env file(s) in main worktree Worktree: ~/my-project (main) Worktree: ~/my-project--feature .env in sync .env.local in sync
Sync & Diff
$ envsync diff envsync diff ──────────────────────────────────────── .env 2 difference(s): + NEW_API_KEY=abc123 ~ PORT=3000 -> 3001 $ envsync sync --merge resolved .env (merge)
Features

Everything you need. Nothing you don't.

envsync does one thing and does it well. Unix philosophy for the modern developer.

⚡

Zero Config

Works out of the box. Just run envsync sync and your .env files are synced.

✓

Conflict Detection

When files diverge, envsync shows you exactly what changed and lets you merge or overwrite.

⇄

Bidirectional Sync

Sync from main to linked, or detect changes in both directions. You stay in control.

🚀

Dry Run Mode

Preview exactly what would change before writing any files. --dry-run keeps you safe.

🔒

Auto-Sync on Checkout

Install the git hook and every branch switch automatically syncs your .env files.

⚙

Monorepo Support

Detects .env files in apps/, packages/, and libs/ directories.

AI Workflows

Built for the age of AI agents

Running multiple AI coding agents in parallel? Each one needs its own environment to avoid port collisions and database conflicts.

Multi-Agent Setup
# Create worktrees for each AI agent $ git worktree add ../agent-feature -b agent-feature $ git worktree add ../agent-bugfix -b agent-bugfix # Sync env to each $ cd ../agent-feature && envsync sync copied .env $ cd ../agent-bugfix && envsync sync copied .env # Each agent gets unique ports via .envsync.toml overrides # Agent 1: PORT=3001, Agent 2: PORT=3002
